# chaoxing-work-cua

> 一个基于 **Computer Use（计算机操作代理）** 的在线作业自动作答 Skill 模板，
> 以超星学习通（chaoxing.com）作业页面为例，沉淀了从读题、作答到保存提交的
> 完整自动化流程，以及实操中踩过的**全部坑**与规避方法。

## 这是什么

这是一个给支持 **Computer Use** 能力的 AI Agent（如 ZCode / Claude Code +
computer-use 插件）使用的 **Skill（技能指令文件）**。安装后，当用户打开在线作业
页面说"帮我做题"时，Agent 会按照本 Skill 沉淀的实战流程完成：

```
读题（截图 + 视觉转录） → 客观题点选 → 填空/简答键盘录入
→ 逐项截图验证 → 暂时保存 → （经用户确认后）提交
```

## ✨ 核心经验（为什么值得用）

全部内容来自真实多轮实操（累计完成 30+ 题、跨 5 份作业、2 个账号），每条规则
都对应一次真实返工：

- **两种工作模式**：CUA 模式（外部浏览器：截图+坐标+键盘）与内置浏览器模式
  （browser-use/IAB：DOM 直读直写，快一个数量级），均含完整踩坑手册
- **表单控件不在无障碍树里** → 读题靠截图+视觉，操作靠坐标+键盘
- **坐标事件要求前台** → 用户一切窗口焦点就会失效，每次操作前重新前台化
- **多标签页标题全部同名** → 必须用 URL 里的 `workId` 校验，否则会答错别人的卷子
- **坐标必须来自当前帧** → 页面一动旧坐标就作废，用"路标+元素间距"推算而不是目测
- **富文本编辑器屏蔽粘贴** → 一律模拟键盘逐字输入（支持中文）
- **段落以"1."开头会触发自动编号** → 变成"2.2."重复，改用"（1）（2）"
- **保存 toast 只有 2 秒** → 错过不代表失败，以最终提交结果页为权威验证
- **章节测验三层 iframe 嵌套 + 题干字体加密** → 链式 frameLocator 穿透 +
  同源 JS 直点 + AI讲解获取正确答案
- ……共 **11 条硬规则 + 14 行报错对照表**，详见 [SKILL.md](SKILL.md)

## 📦 安装

### 方式一：npx 一键安装（推荐）

```bash
npx chaoxing-work-cua
```

会自动把 SKILL.md 安装到已存在的 Agent 技能目录
（按 `~/.agents/skills` → `~/.zcode/skills` → `~/.claude/skills` 顺序检测，
都不存在时装到 `~/.agents/skills`）。

指定安装位置：

```bash
npx chaoxing-work-cua --target "D:\my-agent\skills"
```

### 方式二：手动安装

把 `SKILL.md` 放到你所用 Agent 的技能目录下，例如：

```text
# ZCode / Claude Code 用户技能目录（Windows 示例）
C:\Users\<你>\.agents\skills\chaoxing-work-cua\SKILL.md
```

前置要求：

- Agent 具备 Computer Use / 计算机操作能力（截图、点击、键盘输入）
- 浏览器中已登录作业平台账号，并打开作业页面

## 🚀 使用

1. 在浏览器中打开作业页面（可以同时开多份，Skill 会用 URL 参数区分）。
2. 对 Agent 说："帮我做一下打开的作业 / 依次完成这几份作业"。
3. Agent 会自动：枚举作业 → 读题 → 核实客观题答案 → 逐题作答 → 验证 → 暂时保存。
4. 提交属于不可逆动作，**默认只暂时保存**；确认无误后明确告诉 Agent"提交"即可。

## 🔧 平台适配改造点

模板以学习通为例，换其他在线作业平台只需替换（见 SKILL.md 末尾对照表）：

| 改造点 | 说明 |
|---|---|
| 业务主键参数 | 作业页 URL 中的唯一标识（如 `workId=`） |
| 标签页标题特征 | 用于枚举同名作业标签的正则 |
| 保存/提交按钮文案与坐标 | 重新实测 |
| 富文本编辑器行为 | 自动编号、粘贴屏蔽等特性逐个实测 |
| 布局偏移量表 | 按目标平台重新标定 |
